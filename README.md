🧱 Breakout (Ren'Py)
Implementação de um jogo estilo Breakout (quebra-blocos) utilizando Ren'Py. Este projeto foi desenvolvido como teste técnico, explorando como adaptar uma engine focada em visual novels para um gameplay mais dinâmico.

📌 Descrição
Este projeto recria a mecânica clássica do Breakout:
Controle de uma barra (paddle)
Bola com física simplificada
Sistema de colisão com blocos
Destruição de blocos ao contato
Loop básico de gameplay

O foco principal foi demonstrar lógica de jogo, organização de código e adaptação da engine Ren'Py para um gênero não convencional.

🎮 Funcionalidades
Movimento da barra controlado pelo jogador
Sistema de colisão (bola, paredes, barra e blocos)
Destruição de blocos ao impacto
Reinício do jogo
Estrutura simples e modular

🛠️ Tecnologias
Ren'Py
Python (scripts internos do Ren'Py)

🚀 Como executar
Baixe ou clone este repositório:

git clone https://github.com/matheuspedrosa30/breakout_game.git

Instale o Ren'Py:
https://www.renpy.org/
Copie o projeto para a pasta projects do Ren'Py
Execute o jogo pelo launcher do Ren'Py

🎯 Objetivo do projeto

Este projeto foi desenvolvido como um teste técnico com os seguintes objetivos:

Demonstrar capacidade de adaptação a diferentes engines
Implementar lógica de jogo fora do uso padrão do Ren'Py
Escrever código claro e organizado
Resolver problemas de colisão e controle em um ambiente não nativo para esse tipo de jogo

⚠️ Limitações
Física simplificada (não utiliza engine física real)
Estrutura focada em demonstração, não em produção
Sem sistema avançado de fases ou progressão
