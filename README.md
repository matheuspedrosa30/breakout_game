# 🧱 Breakout (Ren'Py)

Implementação de um jogo estilo Breakout (quebra-blocos) utilizando Ren'Py. Este projeto foi desenvolvido como teste técnico, explorando como adaptar uma engine focada em visual novels para um gameplay mais dinâmico.

---

## 📌 Descrição

Este projeto recria a mecânica clássica do Breakout:
- Controle de uma barra (paddle)
- Bola com física simplificada
- Sistema de colisão com blocos
- Destruição de blocos ao contato
- Loop básico de gameplay

O foco principal foi demonstrar lógica de jogo, organização de código e adaptação da engine Ren'Py para um gênero não convencional.

---

## 🎮 Funcionalidades

- Movimento da barra controlado pelo jogador  
- Sistema de colisão (bola, paredes, barra e blocos)  
- Destruição de blocos ao impacto  
- Reinício do jogo  
- Estrutura simples e modular  

---

## 🛠️ Tecnologias

- Ren'Py  
- Python (scripts internos do Ren'Py)
